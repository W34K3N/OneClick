# OneClick 1.0

Инструмент для переноса приложений и их настроек на чистую Windows.

Идея простая: программа сама находит приложения на текущем ПК, складывает их установщики и
конфиги в папку `Bundle`, а на новой системе ставит всё обратно и возвращает настройки.

## Что нужно

- Windows 10/11 x64, права администратора.
- `winget` (App Installer из Microsoft Store) — используется для поиска и установки пакетов.
- Свободное место: `Bundle` занимает столько же, сколько конфиги и установщики приложений
  (обычно 2–10 ГБ). Перед восстановлением программа проверяет место и предупреждает.

## Как пользоваться

Запустите `OneClick.exe`. На стартовом экране три варианта.

### 1. ЭТО СТАРАЯ WINDOWS

Программа сканирует систему и составляет список приложений:

- пакеты из `winget export`;
- программы из реестра (HKLM x64/x86, HKCU);
- портативные сборки из `%ProgramFiles%`, `%ProgramFiles(x86)%`, `%LocalAppData%\Programs`
  (те, у которых нет деинсталлятора);
- настройки ищутся по типовым путям: `%APPDATA%\<имя>`, `%LOCALAPPDATA%\<имя>`,
  `%PROGRAMDATA%\<имя>` и ключи `Software\<имя>` в HKCU/HKLM.

Проверьте галочки (игры и служебные компоненты отфильтрованы, но лишнее лучше снять) и нажмите
**«СОБРАТЬ ВСЁ»**. Программа скачает установщики в `Bundle\installers` и сохранит конфиги в
`Bundle\configs`. Это может занять 20–60 минут.

### 2. ЭТО НОВАЯ WINDOWS

Скопируйте папку `Bundle` на новый ПК рядом с `OneClick.exe` и нажмите эту кнопку.
Программа по очереди поставит приложения из `Bundle\installers` (или через `winget`, если
установщик не скачался) и вернёт конфиги. Порядок и параметры берутся из `bundle.json`.

### 3. Обычный режим

Список из `manifest.json` — для ручного управления: скрыть/показать пункты, добавить свой
установщик кнопкой «+ ДОБАВИТЬ ФАЙЛ», сохранить только настройки.

## Что внутри Bundle

```
Bundle\bundle.json      список приложений: id, установщик, тип, тихие ключи, конфиги
Bundle\installers\      скачанные установщики и архивы (+ yaml-манифесты winget)
Bundle\configs\         копии настроек: папки, файлы, экспорт реестра (.reg)
Bundle\logs\            журналы каждого запуска
```

`bundle.json` самодостаточен: новая система не требует ни `manifest.json`, ни сканирования.

## Поддерживаемые установщики

NSIS, Inno Setup, MSI, MSIX/APPX, WiX Burn, 7-Zip SFX, InstallShield, Squirrel, portable-папки,
`.zip`-архивы (распаковка в папку приложения), скрипты `.ps1` / `.bat` / `.cmd` / `.reg`.
Если тип не распознан, ключи тихой установки берутся из yaml-манифеста, который winget кладёт
рядом с установщиком.

## Настройки: как сохраняются и возвращаются

- **dir** — папка. Режимы `full` (всё) и `selective` (без кэшей и логов: списки исключений
  задаются в манифесте для каждого приложения).
- **file** — отдельный файл (например `settings.json` у Windows Terminal).
- **reg** — ветка реестра, экспорт и импорт.

При восстановлении копируется всё, что лежит в бэкапе: фильтры `include`/`exclude` действуют
только при сохранении. Поэтому важно, чтобы в исключения не попало нужное (например, у Windhawk
нельзя исключать `*.dll` — там лежат скомпилированные моды).

Дополнительные поля манифеста:

- `restoreSkip` — что не восстанавливать из бэкапа (для папок, где лежит сама программа);
- `preRestore` / `postRestore` — действия до и после восстановления: `service-stop`, `service`,
  `kill`, `restart`, `start` (например, перезапуск службы Windhawk и `explorer.exe`, чтобы моды
  применились сразу).

## Подпись

`OneClick.exe` подписан самоподписанным сертификатом `CN=OneClick Self-Signed`.
На чужом ПК Windows покажет «Неизвестный издатель», пока сертификат не добавлен в доверенные:

```
install-cert.cmd
```

(или вручную: `certutil -addstore -user Root OneClick-cert.cer` и то же для `TrustedPublisher`).
Самоподпись не заменяет платный сертификат — SmartScreen всё равно может предупреждать.

## Ограничения

- Настройки ищутся по именам: если папка приложения называется иначе (например, у VS Code это
  `%APPDATA%\Code`), её нужно добавить вручную.
- Портативные программы вне трёх стандартных каталогов не находятся автоматически.
- `winget uninstall` для пакетов, установленных в профиль пользователя, из-под администратора
  не работает — удалять такие приложения нужно вручную.
- Некоторые деинсталляторы (например WinRAR) требуют нажатий в окне — «тихо» они не удаляются.
- Программа работает только с тем, что видит: установленные приложения и файлы настроек.
- Проверено на Windows 11 24H2 x64, 150 % DPI.

## Журналы

Каждый запуск пишет `Bundle\logs\run-ГГГГММДД-ЧЧММСС.log`. Строки:

- `+` установлено/сохранено, `=` уже стояло, `—` пропущено, `!` ошибка.
